## 项目简介

**项目主题：How Income Shapes Life in Toronto's Neighbourhoods（收入如何影响多伦多社区的生活）**

本项目研究多伦多各社区的收入水平与租房情况、住房成本、住房条件和公共交通使用之间的关系，并比较这些关系在不同社区之间的差异。

我们小组围绕四个研究问题展开分析，以家庭收入中位数作为共同变量，将研究结果联系起来。

## 数据集

**Toronto Neighbourhoods Dataset (STA130 Fall 2026)**

- **数据来源：** [STA130 GitHub Repository](https://github.com/skyepaphora/STA130-FA26/tree/main/Project)
- **数据文件：** `toronto_neighbourhoods_STA130.csv`
- **数据规模：** 158 个社区，80 个变量
- **分析工具：** R

## 小组研究问题

### Q1：收入与租房比例

在多伦多，家庭收入中位数较低的社区，租房住户所占比例是否更高？这种关系在多伦多四个不同区域之间是否存在差异？

### Q2：租金与住房负担

在多伦多各社区中，更高的租金、家庭收入，以及更低的补贴住房租户比例，是否与更多租户将至少 30% 的收入用于住房支出有关？

**延伸问题：** 在低收入居民比例较高的社区中，租金与住房负担之间的关系是否更强？

### Q3：住房年代与维修需求

在多伦多各社区中，老旧住房比例与需要重大维修的住宅比例之间有什么关系？这种关系是否会随着家庭收入中位数的变化而有所不同？

### Q4：收入与公共交通通勤

在多伦多不同社区中，家庭收入中位数与公共交通通勤比例之间存在怎样的关系？这种关系在以高层住宅为主的社区和其他社区之间是否有所不同？
